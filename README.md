# 图解舌诊：在线交互沙盘

基于罗大伦《图解舌诊：伸伸舌头百病消》（江西科学技术出版社，2015，全书 205 页）整理的**纯静态零依赖在线交互沙盘**，可直接部署至 GitHub Pages 或任意静态 Web 托管服务。

> **健康筛查边界与医学免责声明**  
> 本项目整理的舌诊知识仅作为日常自我健康筛查参考（**只给怀疑的权利，不给诊断的权利**），不具备临床医疗诊断效力。若发现异常舌象或怀疑存在器质性疾病（如新发舌尖偏斜、大便带血、胸闷胸痛、甲状腺/乳腺结节、妇科包块等），请务必及时前往正规医院由执业医师确诊；任何药方与食疗均为阶段性补救措施，健康根本在于良好的情绪、合理的饮食与积极的锻炼。

## 核心特性

- **零外部运行时依赖**：纯原生 HTML5 / CSS（`@layer`）/ Vanilla JS，无打包工具链、无外部 CDN、无第三方统计或追踪脚本。
- **宣纸暖白单主题与原色舌图**：采用统一纸本浅色视觉；38 幅原书 WebP `q80` 临床插图不施加任何 CSS 色相、饱和度或对比度滤镜，完整保留辨证所需真实色泽。
- **全局即时检索（`Ctrl/Cmd + K`）**：跨 10 章骨架、7 大体质、39 种舌象、27 种调理方法与单味药材毫秒级检索直达。
- **六大交互视图（`书 · 诊 · 镜 · 鉴 · 方 · 测`）**：
  1. **〔书〕全书骨架与七大体质**：10 章逻辑骨架树、7 大体质全景档案与详情检视。
  2. **〔诊〕舌面脏腑分区**：可点击交互舌面 8 大脏腑分区热区图，支持一键切换原书插图。
  3. **〔镜〕照镜分路自查**：12 项观舌前假象排除闸门 + 4 步分支决策树 + 复合体质先后调理原则。
  4. **〔鉴〕原书图鉴与易混对比**：按风险等级、警示标签、体质与分区筛选 39 种舌象，并支持 8 组易混舌象同屏并排鉴别。
  5. **〔方〕调理方法与红线**：覆盖茶饮、泡脚、食疗、中成药与穴位调养，标注精确用量、煎煮方法、加减法与禁忌红线。
  6. **〔测〕病因传导与闯关自测**：跨章病因传导交互拓扑图 + 16 道临床情景自测题与原书页码解析。

## 本地预览

无需安装 Node.js 或任何构建工具，在仓库根目录启动任意静态文件服务器即可预览：

```bash
python3 -m http.server 8000
```

随后在浏览器打开 `http://localhost:8000/` 即可访问。

## 部署至 GitHub Pages

1. 将本仓库推送至 GitHub 的 `main` 分支。
2. 进入 GitHub 仓库的 **Settings -> Pages**。
3. 在 **Build and deployment** 中配置：
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / `/ (root)`
4. 点击 **Save** 后等待约 1 分钟，即可通过 `https://<your-username>.github.io/<repo-name>/` 在线访问。
